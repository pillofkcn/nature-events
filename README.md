# Nature Events

A Flutter app that shows natural events happening around the world right now
(wildfires, volcanoes, severe storms, icebergs, floods) using the free
[NASA EONET API](https://eonet.gsfc.nasa.gov/docs/v3).

Course project for VAI (UKF Nitra). Work in progress – currently only the project skeleton.

## Project structure

```text
lib/
├── models/      data models
├── providers/   state management (Provider)
├── widgets/     custom widgets
├── screens/     app screens
└── main.dart    entry point
```

## Run

```sh
flutter pub get
flutter run
```
